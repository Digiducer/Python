# Python
TMS_Digital_Audio.py is a python example to access data from TMS devices. The Modal Shop Python Example.pdf explains this example in more detail.

simpleDigi.py is a very basic example of how to access data from any sound device that is accessible on your computer. Visit https://www.youtube.com/watch?v=0LOlDqQFy74 to see how this script runs.

findDigiImport.py extends on simpleDigi.py to make sure that the first Digi device found is the device that is used to record data. It also accesses the calibration information and assigns units to the data. If no Digi device is found the app terminates. FindDigiDevices.py is used to find the Digi devices present on your computer and is required to run this python script. Visit https://www.youtube.com/watch?v=78lyxSepU9Y to see how this script runs.
